📄 DIN 5008 Delivery Note

Professional German Delivery Documentation for Odoo

Odoo 19.0 DIN 5008 German

🎯 Overview

This module provides a fully compliant DIN 5008 delivery note (Lieferschein) template for Odoo. It features an extended information block, automatic position numbering, and seamless integration with sales orders and inventory management.

✨ Key Features

📋 DIN 5008 Compliant

Follows official German business correspondence standards

🎨 Modern Typography

Uses professional Montserrat font throughout

📊 4-Column Table

Position, Item, Ordered, Delivered quantities

🔢 Auto Numbering

Automatic position numbering (010, 020, 030...)

🔗 Sales Integration

Pulls data from sale orders and projects

🌍 Origin Display

Shows countries of origin from products

📦 Information Block

The delivery note includes comprehensive order information:

  • Contact person (Salesperson)
  • Email and phone number
  • Order date and reference
  • Customer number
  • Purchase order number and date
  • VAT identification number
  • Vendor/Supplier number
  • Country of origin
  • Project reference

🎯 Use Cases

  • B2B manufacturing companies
  • German businesses requiring DIN 5008 compliance
  • Companies with international trade (country of origin)
  • Businesses tracking customer PO numbers
  • Project-based delivery tracking

🔧 Technical Details

Dependencies:

  • stock: Core inventory module
  • sale_stock: Sales and stock integration
  • l10n_din5008: German DIN 5008 base module

New Fields Added:

  • Partner: Purchase Order Number, PO Date, Supplier Number

Languages:

  • English (default)
  • German (complete translations)
