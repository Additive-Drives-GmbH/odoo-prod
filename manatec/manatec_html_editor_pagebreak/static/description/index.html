manaTec HTML Editor Page Break (Seitenumbruch)

Add manual page breaks in Odoo's HTML editor and PDF reports

This module adds a convenient page break (Seitenumbruch) feature to Odoo's HTML editor. Users can easily insert page breaks via the Powerbox command or shorthand, view them clearly in the editor backend, and ensure they render as clean page breaks in PDF reports and print outputs.

Key Features

  • Powerbox Commands & Shorthands: Quickly insert a page break by typing /pagebreak or /seitenumbruch in the HTML editor, or via the Powerbox menu.
  • Editor Backend Preview: Displays a dedicated non-editable visual marker element so users can easily identify page breaks while editing content.
  • PDF Reports & Print Integration: Automatically triggers clean page breaks (page-break-after: always / break-after: page) in PDF reports (such as sale orders, invoices, and custom reports) while hiding visual editor decorations.
  • Dark & Light Mode Styling: Fully optimized visual styling for both Odoo light mode and dark mode interfaces.

Technical Details

  • Plugin & Architecture: Implements PageBreakPlugin built on Odoo 19 HTML editor plugin system.
  • Asset Integration: Includes SCSS styles for editor backend, frontend, readonly views, PDF report bundles (web.report_assets_pdf), and dark mode (web.assets_web_dark).
  • Dependencies: html_editor
