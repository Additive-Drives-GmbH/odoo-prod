manaTec Contact NDA

NDA Expiry Tracking and Reminders for Contacts

This module extends Odoo Contacts with an NDA Valid Until date field and a scheduled action that creates a reminder activity a configurable number of months before expiry, assigned to a sensibly-chosen responsible user.

Features

  • Contact Extension: Adds nda_valid_until (Date) to res.partner, shown in the "Sales & Purchase" tab.
  • Scheduled Action: Adds a "Contact: Check NDA Expiry" scheduled action that runs daily and creates a reminder activity a configurable number of months before the NDA's expiry date.
  • Logic Lives in the Cron, Not the Module: No extra database fields, and no Python method in the module either — the months-before threshold, the activity type, the default responsible user, and the full reminder logic are plain, freely editable Python directly in the scheduled action's code.
  • Responsible User Logic: If exactly one of the contact's Salesperson or Buyer is set, that person gets the activity; if neither or both are set, the configured default user is used instead.
  • No Duplicate Reminders: A contact already having a pending activity of the configured type is skipped.
  • Localized Date: The activity summary shows the expiry date formatted according to the responsible user's language.

Technical Details

  • Models Modified: res.partner: Adds nda_valid_until (Date) only.
  • Views Modified: base.view_partner_form: Adds the NDA field.
  • Data: Ships the "Contact: Check NDA Expiry" scheduled action, including its full reminder logic, inactive by default.
  • Dependencies: purchase, mail
